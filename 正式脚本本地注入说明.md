# Hướng dẫn inject cục bộ cho script chính thức

File này dùng để tránh việc sau khi ngữ cảnh bị nén (context compression) thì quên mất cách test.

## Quy tắc tiếp nối sau khi nén ngữ cảnh

Nếu người dùng không nói "build lại", "inject lại", "mở không được nữa" hoặc "script bị lỗi rồi", thì mặc định coi script chính thức trong trang Tavern hiện tại vẫn đang ở trạng thái đã inject, không chạy lại từ đầu toàn bộ quy trình build, khởi động service, inject lại.

Khi tiếp tục test sau khi nén, chỉ cần kiểm tra ngắn gọn:

1. Xác nhận trang chính của Tavern vẫn tồn tại `window.tangquanFrontend`, `window.tangquanZeroLayer`, `#chat > .mes[data-tq-visual-zero="true"]`, `#tangquan-game-ui-host`.
2. Nếu các object này tồn tại, tiếp tục nghiệm thu trực tiếp từ trạng thái UI hiện tại: nút bấm, AIRP, bộ nhớ trang, log.
3. Nếu object tồn tại nhưng UI đang bị thu gọn, chỉ cần bấm `打开未开之花` (Mở Hoa Chưa Nở) để mở lại; nút này không phải là cổng inject.
4. Chỉ khi xác nhận instance script không còn tồn tại, sản phẩm build đã thay đổi, service 8879 bị ngắt, hoặc người dùng yêu cầu rõ ràng, mới thực hiện lại hai phần "service cục bộ" và "inject script".

Trạng thái QA hiện tại của gameplay chủ tiệm lấy kết luận trong mục "Ghi chú bổ sung QA script chính thức" của `src/汤泉/项目进度清单.md` (Danh sách tiến độ dự án) làm chuẩn: cổng vào AIRP, gửi thực tế, sửa lỗi thanh nhập liệu, bộ nhớ trang, xác nhận thao tác nguy hiểm, thu phóng cơ sở hạ tầng và dọn dẹp tầng QA đều đã pass.

## Cơ chế vận hành sau khi inject

Sau khi inject thành công, `dist/汤泉/脚本/零层美化/index.js` sẽ chạy trong iframe script của Tavern Helper, và expose controller ra trang chính của Tavern:

- `window.tangquanFrontend`: controller tổng chính thức của frontend, bao gồm các service lưu trữ, world book, MVU, UI, log, loading, v.v.
- `window.tangquanZeroLayer`: controller host tầng 0, chịu trách nhiệm gắn UI vào tầng (floor) của Tavern, và giữ mirror khi tầng refresh, xóa tầng, gắn lại.
- `window.tangquanZeroLayerEmergencyDisable`: hàm gỡ khẩn cấp, dùng để tắt UI và điều khiển tầng 0 do script này gắn vào.

Sau khi script load sẽ tự động `gameUi.open()`, và đăng ký `打开未开之花` (Mở Hoa Chưa Nở) trong thời gian chạy, để dùng khi giao diện bị thu gọn bằng nút X thì có thể mở lại. Khi script bị gỡ hoặc tắt sẽ tự động dọn nút này.

## Script chính thức hiện tại

- Entry mã nguồn: `src/汤泉/脚本/零层美化/index.ts`
- Sản phẩm build: `dist/汤泉/脚本/零层美化/index.js`
- Địa chỉ test cục bộ: `http://127.0.0.1:8879/index.js`

`http://127.0.0.1:8879/index.js` không phải trang preview, cũng không phải cổng vào của character card; nó chỉ là cung cấp `dist/汤泉/脚本/零层美化/index.js` như một file tĩnh cục bộ cho trang Tavern load.

## Vì sao cần inject

Thứ thực sự chạy trong Tavern là iframe script của Tavern Helper. Script chính thức cần được load vào iframe này thì mới có thể dùng được các interface như nút script, biến Tavern, world book, MVU, tầng (floor), v.v.

Vì vậy quy trình test là:

1. Sửa `src/汤泉/脚本/零层美化/**`.
2. Build ra `dist/汤泉/脚本/零层美化/index.js` mới.
3. Dùng service cục bộ để host sản phẩm build này.
4. Inject `http://127.0.0.1:8879/index.js?qa=dấu-thời-gian` vào iframe script của Tavern Helper.
5. Nghiệm thu UI chính thức trong tầng 0 trên trang Tavern.

Không được coi `frontend-*.html` là đối tượng nghiệm thu chính thức; những file đó chỉ giữ lại làm bản tham khảo hình ảnh.

## Service cục bộ

Service test hiện tại nên khởi động với working directory là `dist/汤泉/脚本/零层美化`, để `/index.js` trỏ tới đúng sản phẩm build chính thức:

```powershell
Set-Location "C:\Users\三明月\Desktop\三明月\dist\汤泉\脚本\零层美化"
node -e "const http=require('http'); const fs=require('fs'); const path=require('path'); const root=process.cwd(); const server=http.createServer((req,res)=>{ const url=new URL(req.url,'http://127.0.0.1'); const rel=decodeURIComponent(url.pathname).replace(/^\/+/, '') || 'index.js'; const file=path.resolve(root, rel); if(!file.startsWith(root)){ res.writeHead(403); res.end('forbidden'); return; } fs.readFile(file,(err,data)=>{ res.setHeader('Access-Control-Allow-Origin','*'); res.setHeader('Cache-Control','no-store'); if(err){ res.writeHead(404); res.end(String(err)); return; } res.setHeader('Content-Type', file.endsWith('.js') ? 'text/javascript; charset=utf-8' : 'application/octet-stream'); res.end(data); }); }); server.listen(8879,'127.0.0.1',()=>console.log('tangquan local bundle server http://127.0.0.1:8879/index.js')); setInterval(()=>{}, 1<<30);"
```

Xác minh xem service có trỏ đúng file không:

```powershell
Invoke-WebRequest -UseBasicParsing -Uri "http://127.0.0.1:8879/index.js" -OutFile "tmp\served-tangquan-index.js"
Get-FileHash -Algorithm SHA256 "dist\汤泉\脚本\零层美化\index.js"
Get-FileHash -Algorithm SHA256 "tmp\served-tangquan-index.js"
```

Hai giá trị hash bắt buộc phải giống nhau.

## Script inject

Chạy đoạn sau trong context của trang Tavern, dùng để dọn instance cũ và inject bản build cục bộ mới:

```js
async () => {
  try { window.tangquanFrontend?.dispose?.(); } catch (error) { console.warn(error); }
  try { window.tangquanZeroLayer?.dispose?.(); } catch (error) { console.warn(error); }
  try { window.tangquanZeroLayerEmergencyDisable?.(); } catch (error) { console.warn(error); }

  document
    .querySelectorAll('#tangquan-game-ui-host,#tangquan-loading-overlay,#chat > .mes[data-tq-visual-zero="true"]')
    .forEach(element => element.remove());

  const frames = Array.from(document.querySelectorAll('iframe'));
  const frame =
    frames.find(item => item.id.includes('TH-script--未开之花') || item.name.includes('TH-script--未开之花')) ??
    frames.find(item => item.id.includes('TH-script--【Sanmingyue】预设工具') || item.name.includes('TH-script--【Sanmingyue】预设工具')) ??
    frames.find(item => item.id.startsWith('TH-script--') || item.name.startsWith('TH-script--'));

  if (!frame?.contentDocument) {
    throw new Error('未找到可注入的酒馆助手脚本 iframe');
  }

  const doc = frame.contentDocument;
  doc.querySelectorAll('script[data-tq-local-test="true"]').forEach(element => element.remove());

  const script = doc.createElement('script');
  script.type = 'module';
  script.src = `http://127.0.0.1:8879/index.js?qa=${Date.now()}`;
  script.dataset.tqLocalTest = 'true';
  doc.head.appendChild(script);
};
```

## Dấu hiệu thành công

Sau khi inject thành công, trang chính của Tavern cần thỏa mãn:

- `window.tangquanFrontend` tồn tại.
- `window.tangquanZeroLayer` tồn tại.
- `window.tangquanZeroLayerEmergencyDisable` tồn tại.
- `#chat > .mes[data-tq-visual-zero="true"]` tồn tại.
- `#tangquan-game-ui-host` tồn tại, và UI được gắn trong tầng 0.

`打开未开之花` (Mở Hoa Chưa Nở) chỉ nên tồn tại khi script đang chạy: sau khi thu gọn giao diện bằng X có thể dùng nút này để mở lại; khi script bị gỡ sẽ tự động dọn bởi `dispose()`.
